# 모션그래픽

전부 라이브러리 없이 2D 캔버스 + CSS. 세 겹이다.

## 1. 배경 모션 필드 (`fxField`, `#fxField` 캔버스)

- **오로라 실크**: 리본 4개 × 가는 실 16가닥. 사인파 두 개를 겹쳐 흐르게 하고
  `lighter` 합성으로 겹치는 곳이 빛난다. 리본 모양은 `RIBBONS` 배열(기준 높이 `base`,
  진폭 `a1/a2`, 파수 `k1/k2`, 속도 `s1/s2`, 두께 `w`, 색 차이 `dh`, 밝기 `al`).
- **흐르는 먼지**: 화면 면적에 비례해 90~220개. 느린 흐름장을 타고 위로 떠오른다.
- **전환 서지**: `render()`가 `fxField.slide(index, dir, covered)`를 부르면
  `energy = 1`이 되어 시간이 빨라지고 먼지가 진행 방향 반대로 **광속 줄무늬**를 그린 뒤
  잦아든다.
- **섹션 색**: `HUES` 배열의 색이 챕터마다 돌아가며, 내용 슬라이드는 제목의 색을 물려받는다.
  `--hue` CSS 변수로도 내보내서 제목 글로·룰·진행바·하단 점·수평선이 같이 바뀐다.
- **휴면**: 임베드·영상(`slide--embed`), 탭 숨김, 리모컨 창에서는 rAF를 멈춘다.

## 2. 섹션 제목 연출 (CSS, 스크립트가 요소를 만들어 붙임)

- 글자 하나씩 아래에서 접혀 올라오며 블러가 걷힌다 (`.headline .ch`, 48ms 간격).
- 다 올라온 뒤 글자마다 한 번 반짝이는 글린트.
- 뒤에 큰 외곽선 챕터 번호(`.chapter`)가 줌아웃하며 들어와 천천히 표류.
- 제목을 두른 궤도 링 3개(`.orbit`) — 점선, 위성 달린 링, 빠른 호.
- 룰이 그려진 뒤 스파크가 한 번 지나간다 (`.rule::after`).
- 전환 때 화면을 가로지르는 빛줄기(`.wipe`), 방향은 넘기는 방향을 따른다.

## 3. 인트로 파티클 타이틀 (`introFx`)

`h1.title`의 글자를 오프스크린 캔버스에 같은 폰트로 그려 픽셀을 샘플링(최대 약 3200점)하고,
화면 밖 사방에서 소용돌이치며 날아와 글자를 만든다(1.5초, 왼쪽부터). 2초에 실제 텍스트가
블러를 걷으며 나타나고 파티클은 사라지며, 이후 빛 띠가 글자 위를 주기적으로 훑는다.
인트로를 떠났다 돌아오면 다시 재생된다. 위치는 `offsetLeft/Top`으로 잡는다
(3D 변환 영향을 받지 않음). 폰트가 늦게 로드되면 `document.fonts.ready`에서 다시 샘플링.

## 조절 손잡이

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 섹션 색 순서 | `HUES` |
| 오로라 모양·밝기 | `RIBBONS`, `STRANDS`, `SEG` |
| 먼지 수 | `size()`의 `want` |
| 전환 서지 세기·지속 | `energy *= Math.pow(.955, dt)`, `t += ... (1 + energy * 7)` |
| 파티클 타이틀 속도 | `FLY`, `FORM` |
| 글자 등장 간격 | `.headline .ch`의 `48ms` |

`prefers-reduced-motion: reduce`이면 모든 등장 효과를 끄고 텍스트를 바로 보이며,
배경은 슬라이드마다 한 장만 그린다.
