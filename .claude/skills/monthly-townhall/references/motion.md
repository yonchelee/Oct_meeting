# 모션그래픽

라이브러리 없이 손으로 쓴 WebGL 셰이더 + CSS + 짧은 JS. 네 겹이다.

## 1. 리퀴드 필드 (`fxField`, `#fxField` 캔버스, WebGL)

- **메시 그라디언트 셰이더**: 도메인 워핑한 fbm 노이즈(3단 겹침)로 액체가 흐르듯
  색이 섞이고, 접히는 곳에 광택 리지가 생긴다. 셰이더 안에서 필름 그레인과 비네트까지 처리.
  반해상도(최대 폭 1100px)로 그려 CSS로 늘린다 — 부드러운 화면이라 티가 안 나고 GPU가 가볍다.
- **챕터 팔레트**: `PALETTES` — 챕터마다 `[바탕, 주색, 보조색, 하이라이트]` 4색과 `hue`.
  장이 바뀌면 4색이 약 1초에 걸쳐 섞여 넘어가고, `hue`는 `--hue` CSS 변수로 나가
  제목 글로·스윈·진행바·하단 캡슐·커튼 색을 같이 바꾼다. 내용 장은 제목 장의 팔레트를 물려받는다.
- **전환 서지**: `fxField.slide(index, dir, covered)` → `energy = 1`. 워프가 세지고
  흐름이 넘기는 방향으로 쏠렸다가 잦아든다.
- **휴면**: 임베드(`slide--embed`), 탭 숨김, 리모컨 창에서는 rAF를 멈춘다.
- **폴백**: WebGL이 안 되면 캔버스를 숨기고 `.backdrop`의 CSS 그라디언트가 보인다.
- 위에 옅은 **도트 그리드**(`.grid`)가 깔린다.

## 2. 키네틱 타이포그래피

- **마스크 리빌**: `data-split="words"|"chars"` 또는 `.headline`은 단어(글자)마다
  `<span class="w"><span class="wi">`로 쪼개져, 마스크 아래에서 살짝 기울어진 채 솟아오른다(90ms 간격).
- **스윈**: 다 올라온 뒤 빛이 단어를 한 번 훑는다(배경 클립 텍스트 그라디언트).
- **리퀴드 크롬**: 인트로 "소통"은 채움 그라디언트가 계속 흐른다. 반복 타일 이음매가
  생기지 않도록 그라디언트 각도는 **90deg**로 둔다(비스듬하면 이음매가 보인다).
- **스크램블**: `data-scramble` 요소(인트로 eyebrow, "Chapter 0N" 키커)는 장에 도착할 때
  무작위 글자에서 해독되듯 나타난다.

## 3. 챕터 장식 (스크립트가 마크업에서 생성)

- **오도미터 번호**: 왼쪽 아래 큰 외곽선 "01"이 숫자 띠를 굴려 자리를 잡는다, 옆에 "/ 05".
- **마퀴 띠 2줄**: 제목을 거대한 외곽선으로 반복하는 띠(-5°)와 작은 캡션 띠(3°)가
  반대 방향으로 흐른다. 보이는 장에서만 돈다.
- **키커**: 짧은 선 + "CHAPTER 0N".

## 4. 페이지 전환 커튼 (`.veil`)

넘기는 방향에서 챕터 색 커튼이 덮고(0.38초) 반대쪽으로 걷힌다(총 0.95초). 덮인 동안
도착할 장의 번호와 제목이 잠깐 뜬다. 등장 애니메이션은 커튼이 덮인 뒤(`VEIL_IN`)에 시작해서
커튼이 걷힐 때 글자가 솟아오른다.

## 그 밖

- 하단 컨트롤은 **리퀴드 글래스** 바(블러+채도+윗면 하이라이트), 현재 장 점은 빛나는 캡슐로 늘어난다.
- 인트로의 "2026 · 10" 글래스 필.

## 조절 손잡이

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 챕터 색 | `PALETTES` |
| 흐름 속도 | 셰이더 `uTime*.05`, `frame()`의 `t += .016 * dt` |
| 배경 밝기 | 셰이더 `col*=.74+uPulse*.25` |
| 서지 세기·지속 | `energy *= Math.pow(.95, dt)`, 셰이더 `uPulse` 사용처 |
| 커튼 길이 | `.veil.go/.back`의 `.95s`, JS `VEIL_IN` |
| 단어 등장 간격 | `.wi`의 `90ms` |
| 마퀴 속도 | `.mq-track` `38s` / `.marquee--b` `52s` |

`prefers-reduced-motion: reduce`이면 커튼·마퀴·리빌·스크램블을 끄고 텍스트를 바로 보이며,
배경 셰이더는 장마다 한 장만 그린다.

## 5. 쇼릴 오프닝 (`?reel=1`)

주소 끝에 `?reel=1`을 붙이면 맨 앞에 15초 쇼릴(`#reel`)이 들어간다. 없으면 스크립트가 그 장과
점을 지워서 기본 덱은 그대로다. 0.4초 박자로 컷이 넘어간다:
카운터 0000→2026 · "복기" 슬램(RGB 분리) · 좌우 분할 "관계를 읽다→잇다" · 아이리스+고속 마퀴 ·
타일 그리드 · 터미널+글리치 "AI 첫발" · 숫자 컷 3/4/138 · 박스 리빌 특허/출장/퀵 · 3D "AX"+광선 ·
잇고/이루고/나아가다 컷 · 크롭마크 안의 "2026 REPLAY" 락업(유지).

장면마다 `--at`(시작)과 `--len`(길이)만 가진 CSS 타임라인이고, `.reel.play` 한 클래스로 전부
시작한다. JS(`reelOn`)는 카운터·타이핑·타임코드만 맡는다. 재생 중엔 하단 바가 숨고(키는 동작),
끝나면 "다시 보기"가 뜬다. 화면을 클릭해도 다시 재생.
